# 🗺️ Your Git Journey

```text
        CREATE
           ↓
        MODIFY
           ↓
         STAGE
           ↓
        COMMIT
           ↓
        BRANCH
           ↓
         MERGE
           ↓
         PUSH
           ↓
      COLLABORATE
```

Think of Git as a **time machine for your project**.

You make changes → save meaningful versions → experiment safely → collaborate with others.

# 🏆 Workshop Challenge

## Build Your Own Mini Project

Create a small project such as:

- Personal portfolio
- Calculator
- To-do list
- Student profile
- Simple Python program
- HTML/CSS webpage

Then use Git to:

- Create the repository
- Make at least **3 commits**
- Create a feature branch
- Make a change
- Merge the branch
- Push everything to GitHub

### ⭐ Bonus

Open a Pull Request instead of merging directly.

If you can complete this without constantly checking the command sheet, you've leveled up. 🎮

# ⚡ Quick Command Reference

| Task                   | Command                                            |
| ---------------------- | -------------------------------------------------- |
| Check Git version      | `git --version`                                    |
| Configure username     | `git config --global user.name "Your Name"`        |
| Configure email        | `git config --global user.email "you@example.com"` |
| Initialize repository  | `git init`                                         |
| Check status           | `git status`                                       |
| Stage a file           | `git add filename`                                 |
| Stage everything       | `git add .`                                        |
| Commit changes         | `git commit -m "message"`                          |
| View commits           | `git log`                                          |
| Short commit history   | `git log --oneline`                                |
| Create branch          | `git branch branch-name`                           |
| Switch branch          | `git switch branch-name`                           |
| Create + switch branch | `git switch -c branch-name`                        |
| Merge branch           | `git merge branch-name`                            |
| Add remote             | `git remote add origin URL`                        |
| Push                   | `git push`                                         |
| Pull                   | `git pull`                                         |
| Clone repository       | `git clone URL`                                    |

# 🛠️ Workshop Philosophy

Git becomes much easier when you stop treating it like a list of commands.

Instead, understand this:

```text
I changed something
        ↓
Git noticed it
        ↓
I chose what to save
        ↓
I created a commit
        ↓
Git remembers that version
        ↓
I can share it with others
```

That's the core idea.

Everything else builds on top of it.
