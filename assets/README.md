# 🎨 Workshop Assets

This folder is reserved for visuals and supporting assets for the Git & GitHub workshop.

The main workshop currently uses:

- Mermaid diagrams
- Markdown formatting
- Tables
- Code blocks
- Checklists
- GitHub-rendered visuals

The repository intentionally keeps the asset collection lightweight.

If additional images or GIFs are added later, prefer stable sources with clear reuse permissions and add attribution where appropriate.
